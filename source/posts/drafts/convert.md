### Please, Convert Your Files (properly)

A tragedy I've seen many times: Someone renames a .png file to a .jpg file, and they think that their file was magically converted. Suddenly, they get thrown an error because the file isn't actually a JPG.

This is because you're only changing the _name_ of the file extension. Sure, it might say ".jpg" right there, but all of the data in your image is still that of a PNG.

I'll admit that I've done the same thing tons of times when I was still learning how to use a computer. This is why I implore you to use something like [VERT](https://vert.sh/) to convert your files properly and save yourself the headache of trying to figure out why your image isn't working as it should.
